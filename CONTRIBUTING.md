# Contribuindo

1. Siga a instalação de desenvolvimento no README.
2. Crie uma branch para sua mudança.
3. Execute `npm run check` e `npm test`.
4. Para mudanças visuais, verifique a janela padrão e uma largura menor.
5. Abra um pull request explicando o problema, a solução e os testes executados.

Os testes automatizados usam respostas simuladas das plataformas e não precisam
de contas pessoais, cookies ou acesso à mídia de terceiros. Nos testes manuais,
use publicações públicas que você tem permissão para baixar.

Não inclua arquivos baixados, cookies, tokens, ambientes virtuais, `node_modules`
ou instaladores no Git. Não desative a verificação HTTPS para resolver problemas
de certificados. Ao reportar erros, remova URLs privadas e informações de sessão
dos logs anexados.
